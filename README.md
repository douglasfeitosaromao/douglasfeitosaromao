# Hi there, I'm Douglas Feitosa Romão 👋

*Those who code philosophize; those who philosophize, develop.*

Postdoctoral researcher (FAPESP fellow) at FAU-USP, working at the intersection of **digital humanities, philosophy of technology, and applied AI**. I build the systems I also write critically about: intelligent document processing, vector search, RAG, and agentic AI applied to born-digital archives.

Ph.D. in Communication (UFF, with a research stay at Paris 1 Panthéon-Sorbonne / BnF) · B.A. in Philosophy (USP). My working thesis: editing a database's parameters is editing how we see — so I spend my days philosophizing about JOINs and OCR pipelines in more or less equal measure.
